# TUFF SCRIPT

## How to use

1. Create a new folder and use the terminal/command prompt/powershell to go into that directory. Then, clone it with

```
git clone https://github.com/Bosco0808-alt/tuffscript.git
```

2. Next, add a .env file and add

```
GOONER_IP="insert ip here"
```

3. In addition, install the dependencies with this command: (Be sure to install node js and npm first)

```
npm i
```

4. At last, run

```
ts-node ./
```

AND YOU ARE **DONE** (tuff)
